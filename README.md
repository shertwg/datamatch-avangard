# DataMatch: прогноз продаж билетов ХК «Авангард»

## 1. Задача и результат

Прогнозируем `tickets_total`, то есть сколько разовых билетов продастся за всё время продаж, для 17 test-матчей
сезона 2025/26 (M086–M102) в каждой из 8 ценовых зон. Всего 136 строк. Метрика — RMSE.

RMSE на проверке (3 фолда по времени, 43 матча, 344 строки):

| Модель | RMSE |
|---|---|
| Baseline из задания: среднее по зоне (`zone_mean`) | 141,0 |
| Умный baseline: среднее по зоне за текущий сезон, не ниже уже проданного | 135,2 |
| **CatBoost (итоговое решение)** | **124,7** |

Значимость проверили бутстрэпом по матчам (2 000 повторов). Против `zone_mean` выигрыш −16,4, 95% интервал
[−25,5; −7,2]. Против умного baseline выигрыш −10,5, интервал [−20,4; −0,1], это на грани значимости.

Итог — `predictions.csv` в корне репозитория.

## 4. Подход

- **Без утечек.** Все данные берутся через `src/data.py`: остаются только строки с датой раньше `as_of`.
  Если `as_of` позже 15.12.2025, код падает с ошибкой.
- **Валидация «псевдо-сегодня».** Три фолда: 15.12.2023, 25.11.2024 и 20.09.2025. Модель учится на матчах,
  сыгранных до этой даты, и прогнозирует следующие, как в задаче. Случайный сплит и GroupKFold не берём,
  потому что они пускают в обучение будущее.
- **Baseline'ы.** `zone_mean` из задания и умный baseline: среднее по зоне за текущий сезон, не ниже уже
  проданного.
- **CatBoost на срезах продаж.** Каждый сыгранный матч превращается в снимки за 1–40 дней до игры плюс снимок
  «продажи не открыты». Модель предсказывает остаток сверх уже проданного. Отдельные модели для матчей в
  продаже и для неоткрытых.
- **Признаки:** продажи на дату и темп, уровень зоны, календарь, история соперника, КХЛ.
- **Клиппинг:** прогноз не меньше уже проданного и не больше `seats − season_tickets`, округление до целого.

## 5. Допущения

- Дата отсечки — 15.12.2025. Продажи в данных есть до 14.12.2025 включительно.
- `seats`, `season_tickets` (`zones.csv`) и `sales_open` (`matches.csv`) считаем известными заранее для всех
  матчей и по дате не обрезаем.
- Результаты КХЛ в данных заканчиваются 19.11.2025. Позже соперников и форму «Авангарда» модель не видит.
- `season_tickets_daily.csv` (данные до 23.11.2025) модель не использует: места под абонементами берутся из
  `zones.csv`.
- Для 11 test-матчей, продажи на которые ещё не открыты, история продаж обрывается на 15.12.2025.
- Внешние данные не используются. Код читает только файлы из `data/`.

## 6. Ограничения и риски

- **Выигрыш над умным baseline на грани значимости.** Модель разрабатывалась на тех же трёх фолдах, поэтому
  124,7 скорее оптимистичная оценка.
- **Новогодние матчи.** Спрос на них приходит раньше обычного, но в прошлые сезоны его в итоге не становилось
  больше. Модель даёт 73–77% заполнения, аналогия с прошлыми Новыми годами — 56–63%. Риск в обе стороны,
  скорее в сторону переоценки.
- **Зоны 6 и 7** дают основную ошибку (RMSE 202,6 и 218,8): спрос между ними переключается от матча к матчу,
  а цен и схемы зала в данных нет.
