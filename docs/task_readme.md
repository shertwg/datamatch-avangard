# DATA MATCH. Технический трек. Прогноз спроса на билеты

Задание лежит в файле `Задание.pdf`, условия использования в `LICENSE.md`.

## Что нужно сделать

Для каждого из 17 матчей с пометкой `test` и каждой из 8 ценовых зон предскажите `tickets_total`, то есть сколько билетов продастся на этот матч в этой зоне за всё время продаж. Заполните файл `data/submission_template.csv` и пришлите его под именем `predictions.csv`.

Точность считаем по RMSE (корень из средней квадратичной ошибки) по всем 136 строкам. Прогноз сравниваем с реальными продажами, которых в папке нет.

## Что лежит в папке data

| Файл | Строк | Что в одной строке |
|---|---|---|
| `matches.csv` | 102 | домашний матч |
| `sales_daily.csv` | 23 039 | продажи билетов в одной зоне за один день |
| `season_tickets_daily.csv` | 1 586 | продажи абонементов одного вида в одной зоне за один день |
| `zones.csv` | 816 | одна зона на одном матче |
| `khl_games.csv` | 2 033 | матч КХЛ из открытых источников |
| `submission_template.csv` | 136 | строка ответа: матч и зона |

## Поля

**matches.csv**

| Поле | Что это |
|---|---|
| `match_id` | номер матча от M001 до M102 по порядку дат |
| `season` | сезон 2023/24, 2024/25 или 2025/26, в каждом по 34 матча |
| `date`, `time` | дата и время начала матча |
| `weekday` | день недели, 1 значит понедельник, 7 значит воскресенье |
| `opponent` | соперник |
| `opponent_khl` | тот же соперник, но так, как он записан в `khl_games.csv` |
| `sales_open` | день, когда открылись продажи |
| `part` | `train`, если итог известен (85 матчей), и `test`, если его нужно предсказать (17 матчей) |

**sales_daily.csv**

| Поле | Что это |
|---|---|
| `match_id`, `zone` | матч и ценовая зона от 1 до 8 |
| `date` | день продажи |
| `days_before` | сколько дней оставалось до матча, 0 значит день матча |
| `tickets` | сколько билетов продали в этот день |

**season_tickets_daily.csv**

| Поле | Что это |
|---|---|
| `season`, `date`, `zone` | сезон, день продажи и зона |
| `package_matches` | на сколько матчей рассчитан абонемент |
| `abonements` | сколько таких абонементов продали в этот день |

**zones.csv**

| Поле | Что это |
|---|---|
| `match_id`, `zone` | матч и зона |
| `seats` | сколько мест в зоне |
| `season_tickets` | сколько из них на этот матч занято абонементами |

**khl_games.csv** содержит поля `season`, `date`, `stage` (стадия турнира), `home` и `away` (хозяева и гости), `home_goals` и `away_goals` (счёт).

**submission_template.csv** содержит поля `match_id`, `zone` и пустую колонку `tickets_total`. В неё нужно вписать целое число не меньше нуля.

## Как получить итог для матчей train

Сложите `tickets` по всем дням нужного матча и зоны в `sales_daily.csv`. Продажи на эти матчи уже закончились, поэтому сумма и есть итог.


## Что важно знать

- Данные собраны утром 15 декабря 2025 года. Продажи в файлах есть только до 14 декабря включительно, матчи КХЛ только до 15 декабря. Пользуйтесь только тем, что было известно на эту дату.
- На 6 матчей из test продажи уже начались, их строки есть в `sales_daily.csv`. На остальные 11 продажи ещё не открылись. Предсказывать нужно итог за всё время, вместе с уже проданными билетами.
- Продать больше, чем `seats` минус `season_tickets`, нельзя.
- В данных только количество билетов, цен нет. Абонементы и бесплатные билеты в `tickets` не входят.
- Если в `sales_daily.csv` нет строки за какой-то день, значит в этот день в зоне ничего не продали.
- Зона 1 самая дорогая, зона 8 самая доступная.
