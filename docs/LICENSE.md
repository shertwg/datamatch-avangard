# Условия использования

Данные даёт ХК «Авангард» только для участия в хакатоне DATA MATCH 2026. Скачивая их, вы соглашаетесь с условиями ниже.

**Можно**

- работать с данными внутри своей команды
- публиковать своё решение: выводы, презентацию, описание метода, графики и общие цифры, а также до 20 строк итоговой таблицы

**Нельзя**

- публиковать, передавать или продавать данные и любые их части, в том числе через GitHub, Kaggle, облачные диски и чаты
- выкладывать код и ноутбуки решения в открытый доступ, код получает только жюри
- загружать данные в сервисы, которые их хранят или учатся на них
- использовать данные вне хакатона

**Срок.** Пользоваться данными можно до конца хакатона и ещё 30 дней после. Потом удалите все копии.

**Если правила нарушены,** команду дисквалифицируют, а право на данные прекращается. Данные даются как есть. Действует право Российской Федерации.
